# Laboratorio Semana 1

## Linux
1. `cp config/thresholds.conf.example config/thresholds.conf`
2. `chmod +x scripts/linux/install.sh scripts/linux/monitor.sh`
3. `./scripts/linux/install.sh`
4. `./scripts/linux/monitor.sh`
5. `cat logs/monitor.log`

## Windows
1. `.\scripts\windows\install.ps1`
2. `.\scripts\windows\monitor.ps1`
3. `Get-Content .\logs\monitor.log`
